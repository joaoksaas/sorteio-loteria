# 🎰 Sorteador de Loterias Automatizado

Um script em Python simples e eficiente para realizar sorteios de números aleatórios, simulando modalidades populares de loteria brasileira e permitindo sorteios personalizados.

## ✨ Funcionalidades

- **Modalidades Pré-definidas:** Sorteios rápidos para Mega-Sena, Lotofácil e Quina.
- **Modo Personalizado:** Defina a quantidade de números, o limite mínimo e o limite máximo do intervalo.
- **Interface Interativa:** Menu intuitivo via terminal com validação robusta de entradas.
- **Segurança de Entrada:** O sistema impede erros de digitação (letras ou símbolos) e garante que as regras de negócio sejam respeitadas.
- **Multiplataforma:** Limpeza automática do console compatível com Windows e sistemas Unix.

## 🚀 Como usar

1. **Pré-requisitos:** Certifique-se de ter o [Python](https://www.python.org/) instalado em sua máquina.
2. **Clone o repositório:**

```bash
git clone https://github.com/joaoksaas/sorteio-loteria.git
```

3. **Acesse a pasta e execute o arquivo principal:**

```bash
cd sorteio-loteria
python loteria.py
```

## 🖥️ Exemplo de Execução
Ao iniciar o script, você verá um menu como este:

```text
********************************************************************
Sorteio de loteria automático
********************************************************************

Opções:
1 - Megasena (6 números entre 1 e 60)
2 - Lotofácil (15 números entre 1 e 25)
3 - Quina (5 números entre 1 e 80)
4 - Personalizado (defina a quantidade de números e o intervalo)
0 - Sair
********************************************************************

Escolha uma opção (1, 2, 3 ou 4):
```
